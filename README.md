# SME Profit & Inventory Intelligence

A SaaS-style business intelligence and inventory management platform
designed for small and medium-sized businesses.

## Features

- Product and inventory management
- Multi-warehouse stock tracking
- Sales management
- Purchasing management
- Customer management
- Supplier management
- Revenue and profit analytics
- Inventory valuation
- Low-stock alerts
- Role-based access control
- AI-powered business insights

## Tech Stack

### Frontend
- React
- TypeScript
- Tailwind CSS

### Backend
- Python
- FastAPI
- SQLAlchemy

### Database
- PostgreSQL

### DevOps
- Docker
- Docker Compose
- GitHub Actions

## Architecture

React → FastAPI → PostgreSQL
